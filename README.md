# 枪战01

单人「吃鸡」风格的第三人称 3D 射击游戏（iOS，SceneKit 引擎），全部画面、贴图、模型和音效都由代码实时生成。

## 内容

- 两张地图：**翠屿**（海岛、小镇、港口、军事基地）和 **冰河峡谷**（雪山、冰河、大坝、林场、兵营）
- 飞机航线跳伞 → 搜房子捡装备 → 毒圈逐步缩小 → 和 AI 打到最后一人
- 武器：M416、AKM、UZI、Kar98k、S12K、P92，破片手榴弹、烟雾弹
- 配件：红点、2 倍、4 倍、8 倍镜；头盔、防弹衣、背包（1–3 级）；绷带、急救包、医疗箱、能量饮料
- 载具：吉普车、摩托车
- 第一 / 第三人称切换、左右探头、蹲、趴、跳、换弹、自动拾取
- 画质：流畅 / 高清 / 极致（HDR、泛光、环境光遮蔽、级联阴影、草地、雾）

## 如何得到 ipa

每次推送到 `main` 分支，GitHub Actions 会用云端 Mac 自动编译：

1. 打开仓库的 **Actions** 页面，等待 “Build IPA” 变成绿色 ✅（约 5–10 分钟）
2. 打开仓库的 **Releases** 页面，下载最新版本里的 `QZ01.ipa`
3. 用万能签导入 `QZ01.ipa`，签名后安装

编译日志会保存在 `ci-logs` 分支，方便排查错误。
